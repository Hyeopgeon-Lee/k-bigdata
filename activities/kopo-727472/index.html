특강과 실무 주제

Spring AI 프로그래밍 특강 진행 – LLM과 RAG, Spring AI를 활용한 인공지능 애플리케이션 개발 실습 – 지난 6월 4일, 빅데이터소프트웨어공학과 에서는 재학생들을 대상으로 Spring AI 프로그래밍 특강이 진행되었습니다. 이번 특강에서는 Spring Framework 의 최신 기술 중 하나인 Spring AI 를 중심으로, ChatGPT, LLaMA 등 대규모 언어 모델(LLM)과 연동하는 방법을 실습했습니다.

Spring AI는 Java 기반 애플리케이션에서 인공지능 기능을 쉽게 구현할 수 있도록 도와주는 도구 모음으로, 다양한 LLM과의 연계를 위한 추상화된 인터페이스 를 제공합니다.

학생들의 학습 내용

특강에서는 특히 Vector Storage 기반의 RAG(Retrieval-Augmented Generation) 구현과, Spring AI ChatPDF 기능 을 활용한 문서 기반 질의응답 시스템 구축을 실습하여, 재학생들이 생성형 AI 애플리케이션의 구조와 동작 원리 를 실전 경험을 통해 학습할 수 있는 의미 있는 시간이 되었습니다. 앞으로도 학과는 최신 기술 트렌드를 반영한 다양한 특강과 실습 기회를 통해, 현장 중심의 실무 역량을 갖춘 인재 양성에 힘쓰겠습니다.

활동에 등장한 기술 이해하기

Java는 객체지향 프로그래밍과 기업용 서버 애플리케이션 개발에 널리 활용되는 언어입니다. 대규모 언어모델 LLM은 자연어 입력을 바탕으로 텍스트 생성과 분류, 요약 등 언어 처리 기능을 구현할 때 활용됩니다.
