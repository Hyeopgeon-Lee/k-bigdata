특강과 실무 주제

한국폴리텍대학 서울강서캠퍼스 빅데이터소프트웨어공학과는 지난 4월, 재학생들을 대상으로 LangChain 기반의 LLM(Large Language Model) 애플리케이션 구현 특강을 성공적으로 진행하였습니다. LLM이란? LLM(Large Language Model)은 인간의 언어를 이해하고 생성할 수 있도록 훈련된 인공지능 모델 로, 현재 다양한 산업 분야에서 널리 활용되고 있습니다. ChatGPT, Claude, LLaMA 등이 대표적인 예입니다.

학생들의 학습 내용

특강 주요 실습 내용 LLM 기반 인공지능 시인 만들기 PDF 문서 질의응답 챗봇(ChatPDF) 구현 LangChain 라이브러리를 활용한 실습을 통해 학생들은 실제 서비스를 설계하고 동작시키는 과정을 경험하며 미래 산업에 필요한 실전 역량을 기를 수 있었습니다. 빅데이터소프트웨어공학과는 AI, 빅데이터, 클라우드 컴퓨팅을 융합한 실무 중심 교육을 통해 생성형 AI 시대에 적합한 전문 인재를 양성 합니다. 앞으로도 다양한 최신 기술 특강과 프로젝트 실습으로 학생들의 실무 능력을 강화하겠습니다.

활동에 등장한 기술 이해하기

LangChain은 언어모델을 프롬프트와 데이터, 외부 도구에 연결해 응용 서비스를 구현할 때 사용하는 개발 프레임워크입니다. 대규모 언어모델 LLM은 자연어 입력을 바탕으로 텍스트 생성과 분류, 요약 등 언어 처리 기능을 구현할 때 활용됩니다.

전공과 진로의 연결

‘LangChain으로 배우는 LLM 실전 특강 진행’에서 소개한 기술과 현장 사례를 실제로 구현해 본다면 클라우드·플랫폼·백엔드 개발 직무에 지원할 때 보여줄 결과물이 생깁니다. 특강을 들었다는 이력만 적기보다 핵심 기능을 직접 실습·확장해 코드와 실행 화면을 남기고 기술을 선택한 이유, 어려웠던 점, 해결 방법을 포트폴리오와 면접 답변으로 발전시키는 것이 중요합니다.
