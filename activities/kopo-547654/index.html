모바일 빅데이터의 활용 사례를 소개

학과는 9월 18일 빅데이터 분석 전문기업 넥스엔정보기술의 이영선 대표를 초청해 특강을 진행했습니다. 강연에서는 모바일 빅데이터를 활용한 분석 사례를 소개했습니다. 기업 전문가의 설명을 통해 데이터 분석이 현장의 문제와 어떤 방식으로 연결되는지 살펴보는 시간이었습니다.

분석 도구의 시연으로 살펴본 작업 흐름

강연에서는 빅데이터 분석 도구 Alteryx를 시연했습니다. 사례 설명에 도구의 동작을 함께 보여주는 방식은 데이터를 활용하는 과정을 이해하는 데 도움이 됩니다. 이번 특강은 특정 도구의 기능을 소개하는 데 더해 기업이 데이터를 어떻게 이용하는지 접한 활동이며, 사례 설명과 도구 시연을 통해 분석 업무의 흐름을 살펴본 특강입니다.
