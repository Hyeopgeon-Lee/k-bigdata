연구·발표 내용

학과 졸업생이 대학원 입학에 앞서, 한국정보처리학회 학술대회에서 우수논문상 을 수상한 논문을 확장하여 「The Transactions of the Korea Information Processing Society」(TKIPS) 논문지에 추천받아 정식 게재하였습니다.

논문 제목: 대규모 로그 데이터 분석을 위한 패턴화 압축 기반 빅데이터 처리 시스템 연구 (Study of Pattern Compression based Big Data Processing System for Large Scale Log Data Analysis) 주요 내용: 하둡 기반 분산 시스템 환경에서 패턴화 압축(Zstd)을 적용하여 CPU 사용량 78.8% 감소, 메모리 사용 시간 65% 감소, 처리 시간 80% 이상 향상된 성능을 확인한 실험 기반 연구입니다.

연구의 의미

이번 성과는 졸업생의 우수한 연구역량과 교수진의 적극적인 연구지도 결과로, 앞으로도 학과는 학생들의 학술 역량 강화와 실무 중심 연구 성과 창출을 위해 최선을 다하겠습니다. 많은 축하와 응원 부탁드립니다.
