프로젝트 개요

한국폴리텍대학 서울강서캠퍼스 빅데이터소프트웨어공학과 4기 조정규 학생 은 지난 10월 29일, LF융합기술센터 에서 졸업 작품 “강아지는 훌륭하다 S2”를 전시하였습니다. 작품 소개 “강아지는 훌륭하다 S2”는 반려견 인구가 급증하는 현실을 반영하여 반려인을 위한 커뮤니티 웹사이트 를 구현한 프로젝트입니다. 주요 기능 카카오 로그인 으로 간편한 회원가입 크롤링 기술 을 활용한 견종백과 및 실시간 반려동물 뉴스 제공 ️ 카카오맵 API 를 활용한 지역별 강아지 유치원 위치 안내 게시판 및 실시간 채팅 기능 으로 사용자 간 정보 교류 활성화 이번 졸업작품은 데이터 수집 및 처리, API 활용, 사용자 중심 UI/UX 설계까지 빅데이터소프트웨어공학과의 실무 중심 교육성과 를 잘 보여주는 사례로 주목받았습니다.
