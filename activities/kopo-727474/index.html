2024년 7월 2일, 재학생을 대상으로 Spring Boot의 이해와 활용을 위한 2회차 특강을 진행했습니다. 학생들은 스프링 기반 개발의 작업 순서를 살펴보고 회원가입과 로그인 기능을 구현하는 실습에 참여했습니다.

회원가입과 로그인은 사용자의 입력을 받아 처리하고 결과를 확인하는 웹 서비스의 기본 기능입니다. 익숙한 기능을 직접 만들어 보는 과정은 화면 뒤에서 프로그램과 데이터가 어떻게 연결되는지 이해하는 출발점이 됩니다.

실습에서는 SQL Developer를 사용해 테이블을 생성한 뒤 Spring Boot로 회원가입·로그인 기능을 구현했습니다. 데이터를 저장할 구조를 준비하고 프로그램의 실행 흐름과 연결하는 과정을 경험했습니다.

작업 순서를 따라가며 기능을 구현하면 어느 단계에서 데이터가 입력되고 처리되는지 살펴볼 수 있습니다. 이번 특강은 학생들이 웹 개발의 기본 흐름을 익히고 이후 기능을 확장해 볼 수 있는 기초 실습이었습니다.
