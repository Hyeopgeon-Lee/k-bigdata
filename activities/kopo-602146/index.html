프로젝트 개요

한국폴리텍대학 서울강서캠퍼스 빅데이터소프트웨어공학과 4기 김도우 학생 은 지난 10월 29일, LF융합기술센터 에서 졸업작품 “END(English News Daily)”를 전시하였습니다. 작품 개요 “END(English News Daily)”는 매일 제공되는 영문 뉴스 기사 를 기반으로 실생활에 활용 가능한 실용 영어 단어와 문장 을 학습할 수 있도록 설계된 영어 퀴즈 기반 학습 애플리케이션 입니다.

구현 내용

주요 기능 Korea Herald 1면 기사 자동 크롤링 CoreNLP 기반 자연어 처리 로 주요 단어 추출 NGSL(일상 영어 단어 목록) 기반 퀴즈 자동 생성 음성 녹음 및 발음 비교 분석 (Google TTS 활용) 시각·청각 피드백으로 발음 교정 방향 제시 AWS 서버에 배포: www.englishnewsdaily.ml 이 작품은 빅데이터 분석, 자연어 처리, 음성 인식, AI 기반 영어 학습 기술이 통합된 융합형 프로젝트 로, 학생의 높은 기술 응용력을 보여주는 대표 사례입니다.

앞으로도 학생들의 창의적이고 실용적인 졸업작품을 기대해주세요.

전공과 진로의 연결

‘졸업작품 전시, END English News Daily, 영문 뉴스로 배우는 실용 영어 학습 앱’ 활동에서 확인되는 작품이나 개발 경험은 데이터 분석·시각화 직무를 준비하는 학생에게 포트폴리오 소재가 됩니다. 핵심 기능과 사용자 문제, 담당 부분, 동작 화면을 정리한 프로젝트 결과물에 README, 실행 방법, 문제 해결 기록을 더하면 채용 담당자가 지원자의 실제 구현 범위를 판단하기 쉽습니다. 팀 프로젝트라면 전체 기능보다 본인이 설계·구현한 부분을 명확히 밝히는 것이 중요합니다.
