멘토링 활동

2025년 7월 1일(화) ~ 3일(목) 빅데이터소프트웨어공학과 2학년 선배들이 1학년 후배들을 위해 직접 준비한 스프링부트 프로그래밍 특강이 3일간 성공적으로 진행되었습니다. 주요 실습 내용 공지사항 게시판 구현 회원가입 & 로그인 기능 구현 MyBatis 프레임워크 활용 MariaDB와의 데이터 연동 이번 특강은 선배들이 실무 경험과 노하우를 바탕으로 실습 중심으로 진행하였으며, 1학년 학생들은 실전 개발 감각을 익히고 직접 기능을 구현해보며 큰 성장을 이뤄냈습니다.

특히 후배들의 눈높이에 맞춘 친절한 설명과, 문제 해결 과정에서 함께 고민하며 완성해가는 과정은 진정한 학과 간 멘토링 문화 를 보여주는 시간이었습니다.

선후배 경험 공유

학과는 앞으로도 학생 주도형 실습과 선후배 협력 교육을 통해 더 실용적이고 현장 중심적인 학습 문화를 만들어 나가겠습니다.

활동에 등장한 기술 이해하기

Spring Boot는 자바 기반 서버 애플리케이션을 구성하고 웹 API와 데이터베이스 연동 기능을 구현하는 데 활용됩니다. MyBatis는 SQL을 명시적으로 작성하고 자바 애플리케이션과 데이터베이스 사이의 데이터 처리를 연결하는 프레임워크입니다.

전공과 진로의 연결

선후배의 학습·취업 경험을 비교할 때는 준비 과정에서 활용한 기술, 프로젝트 수행 방식, 진로 선택에 영향을 준 요소를 함께 확인할 수 있습니다.
