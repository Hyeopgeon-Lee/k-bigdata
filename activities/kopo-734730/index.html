파일 형식에 따른 조회 성능 비교

이협건 교수, 김영운 교수와 재학생이 공동으로 작성한 논문이 한국정보전자통신기술학회 추계학술대회에서 우수논문상을 수상했습니다. 논문은 2024년 10월 26일 가톨릭관동대학교에서 발표됐습니다.

연구 제목은 「대용량 데이터 조회 시 효율 향상을 위한 파일 형식에 따른 HIVE 성능 비교 분석」입니다. HIVE에서 사용하는 시퀀스파일, ORC, Parquet의 성능을 비교해 파일 형식이 데이터 처리 속도와 효율에 미치는 영향을 살펴봤습니다.

기술 선택의 근거를 실험으로 확인하기

대용량 데이터를 다룰 때는 같은 내용이라도 저장 형식과 처리 방식에 따라 필요한 자원과 실행 시간이 달라질 수 있습니다. 이 연구는 여러 형식을 같은 주제 아래 비교하고 분석했다는 점에서 데이터 처리 시스템의 설계를 생각해 볼 수 있는 사례입니다.

교수진과 재학생이 공동으로 연구하고 학술대회에서 발표한 경험은 전공 기술을 실험과 분석으로 발전시킨 활동입니다. 이번 수상은 데이터 처리 효율이라는 구체적인 질문에 접근한 학과의 연구 성과를 보여줍니다.
