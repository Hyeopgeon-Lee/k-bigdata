김영운 교수, ICIECT 2025 국제학술대회 논문 발표

김영운 교수가 ICIECT 2025에서 지능형 소프트웨어 로봇을 활용한 데이터 분석 자동화 연구를 발표했습니다. 학과 김영운 교수가 2025년 7월 7일부터 11일까지 베트남 푸꾸옥에서 개최된 제9회 국제정보전자통신기술학회(ICIECT 2025)**에 참가하여 논문을 발표하였습니다.

연구·발표 내용

학과 김영운 교수가 2025년 7월 7일부터 11일까지 베트남 푸꾸옥에서 개최된 제9회 국제정보전자통신기술학회(ICIECT 2025)**에 참가하여 논문을 발표하였습니다.

논문 제목: Automation of Big Data Analysis in Quiz Platform Tasks using Intelligent Software Robot (지능형 소프트웨어 로봇을 활용한 퀴즈 플랫폼 과제의 빅데이터 분석 자동화) 본 논문은 AI 기반 소프트웨어 로봇을 활용하여 퀴즈형 학습 플랫폼 내의 빅데이터 분석을 자동화하는 기술을 제안하였으며, 교육 기술(EdTech) 분야에서의 데이터 분석 효율성과 학습 효과 향상에 기여할 수 있는 연구로 평가받았습니다.

연구의 의미

이번 논문 발표를 통해 빅데이터와 인공지능 기술을 융합한 학습 자동화 분야에서의 연구 역량을 국제적으로 인정받는 성과를 거두었습니다. 앞으로도 김영운 교수님의 활발한 연구 활동에 많은 관심과 응원 부탁드립니다.
