특강과 실무 주제

한국폴리텍대학 서울강서캠퍼스 빅데이터소프트웨어공학과 는 지난 8월 1일(목)부터 2일(금)까지 , 2일간에 걸쳐 SpringBoot 특강 을 성공적으로 진행하였습니다. 1일차 에는 MariaDB 설치 부터 공지사항 웹 페이지 접속까지 실습을 통해 스프링 개발의 기초 환경을 구축하며 기본기를 다졌습니다. ️ 2일차 에는 "공지사항" 템플릿 코드를 기반으로 Spring Boot 프레임워크 구조 에 대한 이해를 높이는 시간을 가졌습니다. ️ 이번 특강을 통해 학생들은 백엔드 웹 개발에 필수적인 스프링부트 활용법을 실무적으로 익히고, 향후 다양한 웹 서비스 개발에 대한 자신감과 실력을 키울 수 있는 기회 가 되었습니다.

활동에 등장한 기술 이해하기

Spring Boot는 자바 기반 서버 애플리케이션을 구성하고 웹 API와 데이터베이스 연동 기능을 구현하는 데 활용됩니다. MariaDB는 SQL 기반으로 데이터를 저장하고 조회할 수 있는 관계형 데이터베이스 관리 시스템입니다.

전공과 진로의 연결

‘Spring Boot 실무 특강, MariaDB 연동, 웹 개발 실습’에서 소개한 기술과 현장 사례를 실제로 구현해 본다면 백엔드·데이터베이스 개발 직무에 지원할 때 보여줄 결과물이 생깁니다. 특강을 들었다는 이력만 적기보다 핵심 기능을 직접 실습·확장해 코드와 실행 화면을 남기고 기술을 선택한 이유, 어려웠던 점, 해결 방법을 포트폴리오와 면접 답변으로 발전시키는 것이 중요합니다.
