## 검토 방식

UI/UX, 학과 홍보, 국문 콘텐츠 편집의 세 에이전트가 병렬로 검토했다. UI 담당은 실제 PC·모바일 화면과 검색 동작을 확인했다. 홍보 담당은 2024~2026년 86건, 편집 담당은 2016~2023년 198건의 제목과 분량을 점검하고 짧은 글과 대표 글을 우선 편집했다. 사용량 제한으로 중단된 편집은 저장된 원고와 검토 결과를 대표 에이전트가 이어받아 적용·검증했다. 외부 전문가의 인적 심사를 받은 것은 아니다.

- 최근 특강·연수·진로체험: 활동 내용, 다룬 기술·직무, 교육적 의미를 소제목과 문단으로 보강했다.

- 목록: 끊긴 요약문을 완결하고 제목·요약·접근성 이름·구조화 데이터를 맞췄다.
- 반복적인 취업 포트폴리오 조언은 활동 자체의 의미를 설명하는 문단으로 바꾸거나 삭제했다.
- 과거 수상 기록 두 건은 게시일과 행사 연도가 충돌해 행사 세부 일자를 단정하는 문장을 제외하고 확인된 수상 내용 중심으로 편집했다. 게시일은 보존했다.

기존 글의 사실과 동일 활동의 기록을 근거로 편집했다. 새 수상 실적, 인원, 인용문, 행사 결과를 만들지 않았다. 기술 설명과 교육적 의미를 덧붙일 때에도 실제 진행된 실습이나 성과로 바꾸어 서술하지 않았다.

## UI 및 공유 기능

- 첫 화면에 ‘활동 찾아보기’와 학생 프로젝트 이동 버튼을 추가했다.
- 검색·필터 사용 시 대표 카드가 사라지면서 검색창이 화면 밖으로 밀리는 현상을 고쳤다.
- 검색어의 마지막 공백이 자동 삭제되어 여러 단어를 입력하기 어려웠던 문제를 고쳤다.
- 모바일 카드 제목은 전체가 보이도록 하고 본문 글자 크기와 터치 영역을 조정했다.
- 상세 글의 안내 영역을 한 곳으로 모아 학생 프로젝트·졸업생 취업현황·입학안내로 연결했다.
- 링크 공유 이미지가 모든 글에서 동일하게 덮어써지던 문제를 고쳐 각 글의 원래 대표 사진을 사용한다.
- 상세 소개문이 짧은 카드 요약으로 덮어써지지 않도록 빌드 처리를 수정했다.
